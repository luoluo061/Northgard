## 下一局由玩家正常操作的验收

1. 开局确认自己身份、地图/模式、双指纹、资源与人口一致；逐组件检查状态。
2. 做一次暂停/恢复：游戏时间不增时，不累计产出、增长或转岗时长。
3. 单人正常调动一名村民/农民到伐木或港口，再调回；对比指派、职业、任务、生产候选和全局缓存变化，保留时间区间。
4. 学习一个明确经济知识、做一次工具/建筑升级；核对原生记录和局部条件变化，不把同时发生的其他变化全归因该加成。
5. 观察一次住房触顶、补房和一次出生；确认进度重置、幸福输入、阻塞提示与有条件ETA，不能由封顶秒数直接算少生人数。
6. 采矿跨阈值、矿藏枯竭/调回、殖民与开工支付、粮食封顶分别对账；矿工共享进度不当作个人连续入账。
7. 完整记录到终局，核对停止原因、尾段、错误/缺口和组件覆盖率，再生成本地贡献包试验；实际上传范围由用户授权。

通过以上验收后再更新稳定性说明。不要把源码可安装、合成测试通过、读到一帧资源或有一个胜利结果，写成新增字段已完成整局验证。
