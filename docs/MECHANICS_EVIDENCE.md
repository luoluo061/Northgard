核对日期：2026-10-27。目标`v4.3.29.43387 / Steam Build 25096976`，双指纹见[规则登记](../mechanics/rules.v1.json)。本轮重新只读解析安装内hlboot与pak中的data.cdb，未调用游戏函数、访问正在运行的对局或修改游戏。编号是此编译版本的函数索引，更新后不可套用。

## 证据分层

| 标签 | 可以声称什么 | 不能替代什么 |
|---|---|---|
| 配置事实 | 当前表中某个字段的数值与引用 | 有效生产、运行条件、最终收入 |
| 代码推导 | 已核指定分支的条件、计算顺序与数值 | 全分支模型、真实输入齐全、实局校准 |
| 真实观察 | 本人局某时间窗内的状态／率／事件 | 因果识别、未观测过程、唯一最优选择 |
| 控制实验通过 | 指定版本和状态内的单因素检验 | 其他氏族／模式和全时段稳定性 |
| 假设／未知 | 候选解释与下一步测量 | 任何补零、固定价格或确定建议 |

未分发完整游戏表、反汇编文本、存档或个人对局。仓库只保存少量核验后的数值事实、公式、来源索引与适用范围。当前基础计算器的控制实验状态仍为`not_run`。

补丁说明用来发现改变与反例；实际模型仍以本机版本和核验条件为边界。社区wiki、视频和熟练玩家经验可提供假说与实验场景，需带版本和反例，不能替代当前计算链。
