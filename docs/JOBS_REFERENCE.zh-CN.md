# 人口转成岗位：先看基础渠道，再看实际工作

绑定本机已核的 `v4.3.29.43337 / Steam Build 25096976` 及机制目录中的双指纹。2026-10-27重新读取已验证PAK内的 `data.cdb`，只投影以下选定渠道。它是配置参考，不是逐人原生实产或完整氏族模拟器；结构化版本见[岗位目录](../mechanics/catalog/common_jobs.v1.json)。

## 基础产量到底是多少

下表的“每月”是固定60游戏秒的基础等价值。必须满足相应岗位持续有效、无加减成；不是预测某个人实际一个月必然入库多少。消费、维护、材料支付和库存上限尚未扣除。

| 岗位／渠道 | 每游戏秒基础值 | 60秒基础等价值 | 前置与容易误读的地方 |
|---|---:|---:|---|
| 村民采食 | 0.4粮 | 24粮 | 必须真的在有效采食；村民职业也可能在走路、施工或战斗 |
| 普通伐木工 | 0.4木 | 24木 | 伐木场渠道；猫头鹰和特殊模式不直接套此卡 |
| 农民 | 0.5小麦 | 30粮 | 非冬季基值；冬季小麦基础先换成村民基础，再走冬罚 |
| 自然猎场猎人 | 0.475肉 | 28.5粮 | 要有对应猎场、岗位资格与有效猎物；诱饵另有渠道 |
| 渔屋渔民 | 0.435鱼 | 26.1粮 | 指 `FishermanHouse` 渠道，不是所有叫渔民的建筑 |
| 普通商人 | 0.2金 | 12金 | 贸易站／市场是可选建筑；不是同一个人同时算两份 |
| 普通港口水手的金币渠道 | 0.2金 | 12金 | `Sailors` 展示标签不能与 `Money` 再相加 |
| 乌鸦港口水手的金币渠道 | 0.25金 | 15金 | 占领等实际工作分支可能替代金币，职业名仍可不变 |
| 普通符文师 | 0.3知识 | 18知识 | 符文石／刻石等是可选渠道，受容量、指派和生产资格限制 |

这些数值来自当前 `unit/<职业>/produce` 的特定条目。不是把整个 `produce` 数组求和：数组里可能包含展示标签、替代渠道、特殊建筑、不同工作选项和氏族分支。水手的知识／声望渠道尤其需要核对港口当前选择，不能把所有行都算为同时生产。

一个最小比较：夏季同样两个人，从有效采食转成有效农田岗位，基础毛粮从48变60，增加12粮／月。不能把60都称作新增收益；施工、走路、材料和维护还没有计入。换成两名有效自然猎场猎人，基础毛粮为57，比48增加9。两名渔屋渔民为52.2，增加4.2。这只能比较这些条件下的粮食毛产，不能据此给全年岗位排座次。

熊的鱼叉会改变鱼产和岗位容量，冬季又会改变采食／种田的规则；地块是否安全、是否能建、需要几人施工、何时开始获益，都可能改变实际选择。选择的比较单位应是完整行动路径和目标时间，见[能力转换](ECONOMIC_CONVERSIONS.zh-CN.md)。

## 这些数值不能直接乘60当库存

| 对象 | 已找到的配置 | 正确读法 | 尚缺什么 |
|---|---|---|---|
| 石矿／铁矿工 | 对应渠道q=0.032 | 开采进度的基础输入，矿藏阈值后离散入账 | 完整共享进度、阈值、最后一块矿和实际到手时间 |
| 酿酒师 | `Happy`基础q=3 | 幸福状态贡献的基础参数；不是每秒存入3幸福 | 完整幸福合成、人口需求与出生门控 |
| 治疗师 | `Healing`基础q=0.429 | 治疗分支的输入；不是本表已验证的单体回血率 | 目标分配、伤病状态、修正及治疗／采食切换 |
| 施工者 | 没有普通`Builder`职业行 | 村民执行施工任务；要连接任务、建筑和进度 | 建造速度、多人施工合并、路程及转岗阶段 |
| 侦察员 | 已有侦察职业与探索任务 | 主要形成地图信息、资源机会和通路；乌鸦另有动态知识分支 | 探索来源、实际探索进度、团队共享视野归因 |
| 锻造者 | 项目工作 | 推进工具／武器／圣物能力，而非直接产生通用库存 | 正常项目报价、施工者占用、完成时间与效果 |

“没有连续库存收入”与“没有收益”是两回事。侦察决定下一块地能不能合法选择；施工把木材和劳动变成未来的岗位；幸福影响未来劳动力。需要先写清形成的能力，再比较它是否赶得上这一局的用途。

## 一个人的实产需要哪些输入

至少需要确认：同一个实体、当前任务、指派建筑、生产资格、季节、受伤／患病／低幸福效果、工具、建筑升级、当地加成、氏族知识、临时效果、模式分支，以及生产缓存对应的时间。只知道人数、工种或建筑有几人，不足以重建最终工资表。

当前采集器记录本方实体链、任务、状态、指派和部分修正输入；逐人最终原生收入与逐人入库账本仍为 `null`。目录中的 `configured_q` 不能填回 `native_actual_rate`。汇总收入除人数也不是逐人实产，特别是在有人受伤、转岗或缓存尚未更新时。

食物消费与新增人口另见[人口经济公式](POPULATION_ECONOMY.zh-CN.md)。熊的知识前置、数值、作用对象与条件路线见[熊族知识参考](BEAR_KNOWLEDGE_REFERENCE.zh-CN.md)。
